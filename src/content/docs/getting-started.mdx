## 系统要求

在安装 Envoy 之前，请确保你的系统满足以下最低要求：

| 项目 | 最低要求 | 推荐配置 |
|------|---------|---------|
| **macOS** | 12 Monterey+ | Apple Silicon (M1+) |
| **Windows** | 10 (x64) | Windows 11 |
| **网络** | 能访问 Manager 服务器 | 局域网或公网 |

> Envoy 是一个桌面客户端应用，需要配合 **Manager 服务器** 才能使用。如果你是团队管理员，请先参阅 [部署指南](/deployment) 搭建 Manager 服务器。

## 安装

### 下载安装包

1. 访问 [下载页面](/download) 获取最新版本的安装包
2. 选择适合你操作系统的版本：
   - **macOS**: `.dmg` 安装镜像
   - **Windows**: `.msi` 安装程序

### macOS 安装

1. 双击打开下载的 `.dmg` 文件
2. 将 **Envoy** 图标拖拽到 **Applications** 文件夹
3. 首次打开时，如遇到"无法验证开发者"提示：
   - 打开 **系统设置 → 隐私与安全性**
   - 点击 **仍要打开** 按钮
   - 或在终端执行：`xattr -cr /Applications/Envoy.app`

### Windows 安装

1. 双击运行 `.msi` 安装程序
2. 按照安装向导提示完成安装
3. 如遇到 SmartScreen 拦截，点击 **更多信息 → 仍要运行**

## 首次启动

启动 Envoy 后，你会看到服务器连接界面。这是使用 Envoy 的第一步 —— 连接到团队的 Manager 服务器。

### 连接 Manager 服务器

Manager 服务器是团队协作的核心枢纽，负责消息路由、任务管理和数据存储。

1. 输入 Manager 服务器的地址，例如：
   - 局域网：`http://192.168.1.100:3000`
   - 本机：`http://localhost:3000`
   - 公网：`https://envoy.example.com`
2. 点击 **连接** 按钮
3. 连接成功后，你将进入登录/注册界面
4. 如果连接失败，请检查：
   - 服务器地址是否正确
   - Manager 服务器是否已启动
   - 网络是否通畅（防火墙是否放行了对应端口）

### 登录或注册

连接 Manager 服务器后：

- **已有团队**：输入用户名和密码，点击登录即可进入工作区
- **新团队**：点击 **创建新团队**，设置团队名称、管理员用户名和密码

> 创建新团队后，你将自动成为团队的 **Leader**（管理员），可以邀请其他成员加入。

## 工作区概览

登录成功后，你将进入 Envoy 的主工作区。界面由以下区域组成：

### 左侧边栏

左侧边栏是导航中心，包含：

- **成员列表** — 显示团队中所有在线和离线成员。点击成员头像可以发起私聊。在线成员头像右下角会显示绿色圆点
- **频道** — 团队公共讨论频道和对话列表。频道以 `#` 标识，私聊以成员头像标识
- **任务中心** — 集中查看和管理所有任务。图标为待处理任务数量角标

### 主内容区

主内容区根据你的操作显示不同内容：

- **聊天窗口** — 与成员私聊或频道讨论时显示消息流和输入框
- **任务面板** — 查看任务详情、上传资源、查看执行日志
- **设置面板** — 个人设置、AI 配置、快捷键等

### 角色说明

Envoy 中有两种角色，角色不同，可执行的操作也不同：

| 角色 | 职责 | 关键操作 |
|------|------|---------|
| **Leader** | 团队管理者 | 创建任务、分派任务、评审任务结果、管理团队设置 |
| **Member** | 团队成员 | 接收任务、执行任务、上传资源、提交结果 |

创建团队的第一个用户自动成为 Leader。后续加入的用户为 Member。
