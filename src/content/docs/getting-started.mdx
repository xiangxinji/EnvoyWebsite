## 系统要求

- **macOS**: 12+ (Apple Silicon / Intel)
- **Windows**: 10+ (x64)

## 安装

1. 访问 [下载页面](/download) 获取最新安装包
2. macOS 用户：打开 `.dmg` 文件，拖动 Envoy 到应用程序文件夹
3. Windows 用户：运行 `.msi` 安装程序，按提示完成安装

## 首次启动

启动 Envoy 后，你会看到登录界面。你需要输入 Manager 服务器地址来连接团队。

### 连接 Manager

1. 输入 Manager 服务器的地址（例如 `http://192.168.1.100:3000`）
2. 点击连接
3. 如果服务器可用，你将进入登录界面

### 登录或注册

- 如果团队已存在，输入用户名和密码登录
- 如果是新团队，选择创建新团队

## 加入团队

登录后你将进入团队工作区。左侧边栏显示：

- **成员列表** — 团队中的所有成员
- **频道** — 团队频道和私人对话
- **任务中心** — 查看和管理任务
