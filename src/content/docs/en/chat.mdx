## Sending Messages

Click any member in the member list to open a private conversation. Type your message in the input box and press Enter to send.

### Rich Text Support

Chat supports the following formats:

- **Markdown** — Bold, italic, code, etc.
- **Code blocks** — Wrapped in triple backticks with syntax highlighting
- **Images** — Drag and drop or paste images
- **Files** — Click the attachment button to upload files

## Channels

Channels are public discussion areas within the team. All team members can view and send channel messages.

### Channel Types

- **General** — The default team channel, all members auto-join
- **Custom** — Team admins can create new channels

## Mentions (@)

Use `@username` in messages to mention a member. The mentioned member will receive a notification.

## Cloud Resource References

Type `@cloud` in a message to reference files from the team cloud resources. Recipients can click to view directly.

## Message Actions

- **Reply** — Reply to a specific message
- **Forward** — Forward a message to another member
- **Delete** — Delete your own messages
