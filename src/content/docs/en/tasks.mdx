## Task Overview

Envoy's task system supports a complete lifecycle: Create → Dispatch → Execute → Review → Complete.

## Creating Tasks

1. Open the Task Center (left sidebar)
2. Click the new task button
3. Fill in the task description and assign an executor
4. Click Create

### AI-Assisted Creation

With AI enabled, you can enter a task description and let AI automatically generate a task plan and dispatch suggestions.

## Task Status

| Status | Description |
|--------|-------------|
| Pending | Task created, waiting for executor to start |
| Running | Executor is working on the task |
| Reviewing | Task completed, waiting for Leader review |
| Completed | Review passed, task closed |
| Failed | Task execution failed |

## Task Dispatch

### Leader Dispatch

Leaders can assign tasks to team members:

1. Select a member in the task panel
2. Fill in task content and requirements
3. Send the task

### AI Dispatch

With AI dispatch enabled, the system automatically assigns tasks based on task descriptions and team member capabilities.

## Task Resources

Executors can upload files as deliverables in tasks:

- Code files
- Documents
- Screenshots
- Any file type

## Task Review

When a Leader receives submitted results, they can:

- View execution process logs
- View uploaded resource files
- Approve or reject task results
- Use AI-assisted review
