## System Requirements

- **macOS**: 12+ (Apple Silicon / Intel)
- **Windows**: 10+ (x64)

## Installation

1. Visit the [download page](/download) to get the latest installer
2. macOS users: Open the `.dmg` file and drag Envoy to Applications
3. Windows users: Run the `.msi` installer and follow the prompts

## First Launch

After launching Envoy, you'll see the login screen. You need to enter the Manager server address to connect to your team.

### Connecting to Manager

1. Enter the Manager server address (e.g., `http://192.168.1.100:3000`)
2. Click Connect
3. If the server is available, you'll proceed to the login screen

### Login or Register

- If a team already exists, enter your username and password to log in
- If this is a new team, choose to create a new team

## Joining a Team

After logging in, you'll enter the team workspace. The left sidebar shows:

- **Member list** — All team members
- **Channels** — Team channels and private conversations
- **Task Center** — View and manage tasks
