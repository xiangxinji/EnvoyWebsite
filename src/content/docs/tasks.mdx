## 任务概述

Envoy 的任务系统支持完整的任务生命周期：创建 → 分派 → 执行 → 评审 → 完成。

## 创建任务

1. 打开任务中心（左侧边栏）
2. 点击新建任务按钮
3. 填写任务描述、指定执行者
4. 点击创建

### AI 辅助创建

开启 AI 功能后，可以输入任务描述，让 AI 自动生成任务计划和分派建议。

## 任务状态

| 状态 | 说明 |
|------|------|
| 待处理 | 任务已创建，等待执行者开始 |
| 进行中 | 执行者正在处理任务 |
| 评审中 | 任务完成，等待 Leader 评审 |
| 已完成 | 评审通过，任务关闭 |
| 失败 | 任务执行失败 |

## 任务分派

### Leader 分派

Leader 可以将任务分配给团队成员：

1. 在任务面板中选择成员
2. 填写任务内容和要求
3. 发送任务

### AI 调度

开启 AI 调度后，系统会根据任务描述和团队成员的能力自动分派任务。

## 任务资源

执行者可以在任务中上传文件作为交付物：

- 代码文件
- 文档
- 截图
- 任意文件类型

## 任务评审

Leader 收到执行者提交的结果后可以：

- 查看执行过程日志
- 查看上传的资源文件
- 批准或驳回任务结果
- 使用 AI 辅助评审
