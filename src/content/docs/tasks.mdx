## 概述

Envoy 的任务系统支持从创建到完成的完整生命周期管理。任务在 Leader 和 Member 之间流转，配合 AI 辅助和 Agent 自动执行，实现高效的团队协作。

### 任务生命周期

```
创建 → 分派 → 执行 → 提交 → 评审 → 完成
                                    ↘ 驳回 → 重新执行
```

## 创建任务

### 手动创建

Leader 可以在任务中心创建新任务：

1. 点击左侧边栏的 **任务中心** 图标
2. 点击右上角的 **新建任务** 按钮
3. 填写任务信息：
   - **任务描述** — 清晰描述任务目标和要求
   - **执行者** — 从团队成员中选择
   - **截止时间** — 可选，设置任务期限
4. 点击 **创建** 按钮

创建后，任务会自动发送给指定的执行者，执行者会收到通知。

### AI 辅助创建

开启 AI 功能后，Leader 可以使用 AI 辅助创建任务：

1. 在任务创建面板中，输入自然语言的任务描述
2. AI 会自动分析描述，生成结构化的任务计划
3. 可以让 AI 根据团队成员的能力自动推荐执行者
4. 确认后一键创建

> AI 辅助创建需要 Manager 服务端配置 AI 提供商。详见 [AI 功能](/ai)。

## 任务状态

任务在生命周期中会经历以下状态变化：

| 状态 | 图标颜色 | 说明 |
|------|---------|------|
| **待处理** (pending) | 灰色圆点 | 任务已创建并分派，等待执行者开始 |
| **进行中** (running) | 蓝色圆点 | 执行者已开始处理任务 |
| **评审中** (reviewing) | 黄色圆点 | 执行者已提交结果，等待 Leader 评审 |
| **已完成** (completed) | 绿色圆点 | 评审通过，任务关闭 |
| **失败** (failed) | 红色圆点 | 任务执行过程中出错 |

### 状态流转规则

- **待处理 → 进行中**：执行者点击"开始执行"
- **进行中 → 评审中**：执行者点击"提交结果"
- **评审中 → 已完成**：Leader 评审通过
- **评审中 → 进行中**：Leader 驳回，执行者需要重新处理
- **任意 → 失败**：执行过程中发生不可恢复的错误

## 任务分派

### 手动分派

Leader 在创建任务时直接指定执行者，任务创建后自动发送给该成员。

分派建议：
- 根据成员的专业领域分配相关任务
- 避免同时给一个成员分配过多任务
- 任务描述尽量清晰明确，包含验收标准

### AI 智能调度

开启 AI 调度后，系统可以根据任务描述和团队成员的能力自动分派任务：

1. 在任务分派面板中输入任务描述
2. 点击 **AI 调度** 按钮
3. AI 分析任务需求，推荐最合适的执行者
4. 确认后自动分派

## 任务资源

任务资源是执行者在任务过程中上传的交付物，Leader 可以在评审时查看。

### 上传资源

执行者可以在任务详情面板中上传文件作为任务资源：

- 点击 **上传文件** 按钮，选择本地文件
- 支持所有文件类型（代码、文档、截图、压缩包等）
- 上传后文件会关联到当前任务
- Leader 评审时可以直接下载查看

### Agent 自动上传

如果任务由 Agent 自动执行，Agent 会在执行过程中自动将生成的文件作为资源上传。

## 任务评审

当执行者提交任务结果后，任务进入 **评审中** 状态，Leader 需要进行评审。

### 评审内容

Leader 可以在任务详情面板中查看以下内容：

- **执行日志** — 任务执行的完整过程记录，包括每一步的推理和工具调用
- **资源文件** — 执行者上传的交付物列表，支持预览和下载
- **最终结果** — 执行者或 Agent 提交的任务总结

### 评审操作

- **通过** — 任务标记为已完成，执行者收到通知
- **驳回** — 任务回到进行中状态，执行者需要根据反馈修改后重新提交

### AI 辅助评审

Leader 可以使用 AI 辅助评审任务结果：

1. 在任务评审面板中点击 **AI 评审** 按钮
2. AI 会分析任务描述、执行过程和提交的资源
3. 给出评审意见，包括是否通过和建议
4. Leader 可以参考 AI 意见做出最终决定

## 任务中心

任务中心是所有任务的集中管理视图，位于左侧边栏。

### 筛选和排序

- **按状态筛选** — 只查看特定状态的任务（待处理、进行中、评审中等）
- **按成员筛选** — 只查看特定成员相关的任务
- **按时间排序** — 最新创建或最新更新的任务排在前面

### 任务卡片

每个任务以卡片形式展示，包含：

- 任务标题和描述摘要
- 当前状态（颜色标识）
- 执行者头像
- 创建时间和最后更新时间
- 资源数量角标
