## 概述

Envoy 的聊天系统是团队日常沟通的核心。支持一对一私聊、团队频道、富文本消息、文件分享和云资源引用，让沟通高效且有序。

## 发送消息

### 私聊

在左侧边栏的 **成员列表** 中，点击任意成员即可打开与该成员的私聊窗口。

- 在输入框中输入文字，按 **Enter** 发送
- 按 **Shift + Enter** 换行
- 消息发送后不可编辑，但可以删除自己发送的消息

### 富文本支持

聊天输入框支持以下格式：

| 格式 | 语法 | 示例 |
|------|------|------|
| **粗体** | `**文字**` | **重要通知** |
| *斜体* | `*文字*` | *稍后处理* |
| `行内代码` | `` `代码` `` | `console.log()` |
| 代码块 | ` ```语言 ` 包裹 | 支持语法高亮 |
| ~~删除线~~ | `~~文字~~` | ~~旧方案~~ |

### 图片发送

Envoy 支持多种方式发送图片：

- **拖拽发送** — 将图片文件直接拖入聊天窗口
- **粘贴发送** — 复制图片后，在输入框中 `Ctrl/Cmd + V` 粘贴
- **附件按钮** — 点击输入框旁的 📎 按钮，选择本地图片文件

发送的图片会在消息流中以缩略图显示，点击可全屏查看。

### 文件发送

点击输入框旁的 **📎 附件按钮**，选择任意文件即可发送。接收方可以直接下载文件。

支持的文件类型没有限制，但建议单个文件不超过 50MB。

## 频道

频道是团队内的公共讨论空间，所有成员都可以查看和发送消息。

### 通用频道

每个团队创建时会自动生成一个 **#通用** 频道。所有新成员自动加入此频道，适合发布团队公告和通用讨论。

### 自定义频道

团队管理员（Leader）可以创建自定义频道，用于按项目、部门或话题组织讨论。

频道的典型用法：

- **#项目名称** — 项目相关的讨论和更新
- **#技术分享** — 技术文章和经验分享
- **#日常闲聊** — 非工作话题的交流

## 消息操作

对已发送的消息，你可以执行以下操作（将鼠标悬停在消息上显示操作按钮）：

### 回复

点击 **↩ 回复** 按钮，可以对特定消息进行回复。回复会以引用的形式显示，方便其他成员了解上下文。

使用场景：
- 回复频道中的特定消息，避免上下文混乱
- 对某条消息进行补充说明或追问

### 转发

点击 **↗ 转发** 按钮，可以将消息转发给其他成员或频道。

转发时会保留原始消息内容和发送者信息，接收方可以看到这是一条转发的消息。

### 删除

点击 **🗑 删除** 按钮，可以删除自己发送的消息。删除操作不可撤销。

> 频道中删除的消息对所有人不可见。私聊中删除的消息仅在删除者的界面消失。

## 提及 (@)

在消息中使用 `@用户名` 可以提及某个成员。被提及的成员会在应用内收到通知。

- 输入 `@` 后会弹出成员列表，可以快速选择
- 被提及的成员名字会高亮显示
- 在频道中使用 `@` 尤其有用，可以确保特定成员注意到重要消息

## 云资源引用

在消息中输入 `@cloud` 可以引用团队云资源中的文件。

1. 输入 `@cloud` 后会弹出云资源文件浏览器
2. 选择需要分享的文件
3. 文件会以卡片形式嵌入消息中

接收方可以直接点击卡片查看或下载文件，无需额外操作。

> 云资源是团队共享的文件存储空间，适合存放项目文档、设计素材等团队共享资源。详见 [任务管理](/tasks) 中的"任务资源"章节。

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Enter` | 发送消息 |
| `Shift + Enter` | 换行 |
| `Ctrl/Cmd + V` | 粘贴图片 |
| `Esc` | 取消回复/取消引用 |
