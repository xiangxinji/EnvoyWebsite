## 概述

Envoy 深度集成了多种 AI 功能，覆盖聊天、任务管理和自动执行三大场景。AI 功能需要在 Manager 服务端完成配置后才能使用。

> AI 功能是可选的。即使不配置 AI，Envoy 的所有核心功能（聊天、任务、文件分享）都可以正常使用。

## 前提条件

AI 功能需要在 Manager Web 管理界面中完成配置：

1. 进入 Manager Web（默认 `http://localhost:5174`）
2. 打开 **设置 → AI 配置**
3. 填写以下信息：
   - **AI 提供商** — 选择 OpenAI 或兼容接口
   - **API 端点** — 接口地址（如使用自定义代理）
   - **API Key** — 你的 API 密钥
   - **模型** — 选择要使用的模型（如 `gpt-4o`、`deepseek-chat` 等）

配置完成后，Envoy 客户端会自动检测 AI 可用性，在聊天和任务界面中显示 AI 相关功能按钮。

## 聊天建议

AI 聊天建议帮助你在对话中快速生成回复。AI 会根据最近的对话上下文，生成一段建议回复文本。

### 使用方法

1. 在聊天输入框旁边，点击 **⚡ 闪电按钮**
2. AI 开始分析最近的对话内容
3. 建议文本以流式方式（逐字）显示在输入框下方
4. 生成完成后，你可以：
   - **接受** — 将建议填入输入框，按 Enter 发送
   - **编辑** — 在建议基础上修改后发送
   - **忽略** — 点击清除按钮或直接输入自己的内容

### 配置选项

在个人设置中，你可以调整聊天建议的行为：

| 设置项 | 默认值 | 说明 |
|--------|--------|------|
| 上下文消息数 | 5 | AI 参考最近 N 条消息生成建议 |

消息数越多，AI 理解的上下文越完整，但消耗的 Token 也越多。

## 自动回复

开启自动回复后，AI 会在收到消息后自动生成并发送回复，适合在忙碌时自动应答。

### 启用自动回复

有两种方式启用/关闭自动回复：

1. **设置面板** — 在个人设置中开启/关闭 **AI 自动回复** 开关
2. **快捷键** — 配置快捷键后，随时按快捷键快速切换

### 工作机制

- 每个对话独立维护 **5 秒防抖定时器**
- 收到消息后等待 5 秒，期间如果没有新消息，AI 才开始生成回复
- 生成完成后自动发送，发送的消息标记为 AI 生成
- **频道消息不触发自动回复**，避免在公共频道中产生噪音

> 自动回复生成的消息会标注来源为 `ai-auto`，团队成员可以看到这是 AI 自动生成的。

## AI 任务管理

AI 在任务管理中提供两个核心能力：任务生成和智能调度。

### 任务生成

Leader 在创建任务时，可以使用 AI 根据自然语言描述生成结构化的任务计划：

1. 在任务创建面板中输入任务描述（如"完成首页 UI 重新设计，包括配色方案和组件布局"）
2. AI 分析描述，生成任务计划，包含：
   - 任务目标拆解
   - 建议的执行步骤
   - 预计交付物
3. Leader 审核并确认后创建任务

### 智能调度

AI 可以根据团队成员的能力和当前负载，自动推荐最合适的任务执行者：

1. 输入任务描述和可选的技能要求
2. AI 分析团队成员列表和历史表现
3. 推荐最合适的执行者，并给出推荐理由
4. 确认后自动分派

## Agent 自动执行

Agent 是 Envoy 最强大的 AI 功能，可以自动执行任务。Agent 使用 ReAct（Reasoning + Acting）循环来逐步完成复杂任务。

### 工作模式

| 模式 | 行为 | 适用场景 |
|------|------|---------|
| **自动模式** (auto) | Agent 收到任务后立即开始执行 | 重复性任务、明确的执行步骤 |
| **手动模式** (manual) | Agent 收到任务后等待确认再执行 | 重要任务、需要人工审核 |

在个人设置中可以切换执行模式。

### Agent 工具集

Agent 拥有以下工具来完成任务：

| 工具 | 功能 | 环境要求 |
|------|------|---------|
| `shell` | 执行终端命令 | 需要 Tauri 桌面环境 |
| `file_read` | 读取本地文件内容 | Tauri |
| `file_write` | 创建或写入本地文件 | Tauri |
| `upload_resource` | 上传文件作为任务资源 | Tauri |
| `cloud_list` | 列出团队云资源目录 | 无 |
| `cloud_upload` | 上传文件到团队云资源 | 无 |
| `read_skill` | 读取技能知识库文件 | Tauri |
| `query_resources` | 查询任务的已有资源 | 无 |
| `read_resource` | 读取任务资源文件内容 | 无 |
| `done` | 声明任务完成 | 无 |

### 执行流程

Agent 执行任务的过程完全透明，你可以在任务详情中查看完整的执行日志：

1. **收到任务** — 检查执行模式，手动模式等待确认
2. **加载技能** — 从 `~/.envoy/brains/{username}/skills/` 加载技能知识库
3. **进入 ReAct 循环**（最多 20 步）：
   - **推理** — AI 分析当前状态，决定下一步操作
   - **工具调用** — 选择合适的工具并传入参数
   - **观察** — 获取工具执行结果
   - **循环** — 根据结果继续推理，直到任务完成
4. **上报结果** — 任务完成或达到步数上限后，提交执行总结和资源

### 工作目录

Agent 在指定的工作目录中执行文件操作：

- 默认路径：`~/.envoy/workspace/{username}/`
- 可在个人设置中自定义工作目录路径

> Agent 执行的命令和文件操作都在工作目录范围内。确保工作目录有足够的磁盘空间。

### 执行超时

- 单个工具执行超时：**60 秒**
- 单步推理超时：**120 秒**
- 输出截断：标准输出超过 2000 字符、标准错误超过 1000 字符会被截断

## 配置汇总

以下设置项与 AI 功能相关，在个人设置中配置：

| 设置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| AI 自动回复 | 开关 | 关闭 | 是否自动回复收到的消息 |
| 上下文消息数 | 数字 | 5 | AI 参考的最近消息条数 |
| 任务执行模式 | 选项 | auto | Agent 自动/手动执行 |
| 工作目录 | 路径 | 默认 | Agent 文件操作目录 |
| 自动回复快捷键 | 快捷键 | 无 | 快速切换自动回复 |
