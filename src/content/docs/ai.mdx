## AI 功能概览

Envoy 集成了多种 AI 功能，帮助团队更高效地协作。AI 功能需要在 Manager 服务端配置 AI 提供商后才能使用。

## 聊天建议

在聊天输入框旁边点击闪电按钮，AI 会根据最近的对话内容生成回复建议。

- 建议基于最近 N 条消息生成（N 可在设置中调整）
- 你可以接受、修改或忽略建议
- 建议通过 SSE 流式生成，实时显示

## 自动回复

开启自动回复后，AI 会在收到消息后自动生成并发送回复。

### 配置

- 在设置中开启/关闭自动回复
- 支持设置快捷键快速切换
- 每个对话独立 5 秒防抖，避免频繁触发
- 频道消息不触发自动回复

## AI 任务调度

在任务分派面板中，可以使用 AI 辅助：

- **任务生成** — 输入描述，AI 生成任务计划
- **智能分派** — AI 根据成员能力自动分配任务

## Agent 执行

Agent 是 Envoy 的高级 AI 功能，可以自动执行任务。

### 工作模式

- **自动模式** — Agent 收到任务后自动开始执行
- **手动模式** — 需要手动确认后 Agent 才开始执行

### Agent 工具

Agent 可以使用以下工具完成任务：

- `shell` — 执行命令行命令
- `file_read` / `file_write` — 读写本地文件
- `upload_resource` — 上传任务资源
- `cloud_list` / `cloud_upload` — 管理云资源
- `read_skill` — 读取技能文件

### 执行流程

1. 收到任务，检查执行模式
2. 加载技能目录
3. 进入 ReAct 循环（最多 20 步）
4. 每步：推理 → 选择工具 → 执行 → 观察结果
5. 任务完成或达到步数上限
6. 上报执行结果

## 配置要求

AI 功能需要 Manager 服务端配置：

- AI 提供商（OpenAI 兼容接口）
- 模型选择
- API Key
- 自定义端点（可选）
