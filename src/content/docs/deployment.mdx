## 系统要求

- **Node.js**: 22.12.0+
- **内存**: 建议 2GB+
- **磁盘**: 根据团队规模，建议 10GB+

## 快速开始

### 1. 获取代码

```bash
git clone https://github.com/xiangxinji/EnvoyClient.git
cd EnvoyClient
```

### 2. 安装依赖

```bash
# 主项目依赖
npm install

# Manager 服务端依赖
npm run manager:server:install
```

### 3. 启动 Manager

```bash
npm run manager:server
```

Manager 服务默认运行在 `http://localhost:3000`。

### 4. 启动 Manager Web

```bash
npm run manager:web
```

Manager Web 管理界面默认运行在 `http://localhost:5174`。

## 配置

### 环境变量

Manager 服务端支持以下环境变量：

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `PORT` | 3000 | 服务端口 |
| `DATA_DIR` | `./data` | 数据存储目录 |

### AI 配置

在 Manager Web 管理界面中配置：

1. 进入设置页面
2. 填写 AI 提供商配置
3. API 端点和密钥
4. 选择模型

## Docker 部署

```bash
docker build -t envoy-manager .
docker run -d -p 3000:3000 -v envoy-data:/app/data envoy-manager
```

## 网络配置

团队成员需要能够访问 Manager 服务：

- 确保防火墙允许对应端口
- 局域网部署使用内网 IP
- 远程部署建议使用 HTTPS

## 数据备份

数据存储在 `DATA_DIR` 目录中，定期备份该目录即可。

```bash
# 手动备份
cp -r ./data ./data-backup-$(date +%Y%m%d)
```
